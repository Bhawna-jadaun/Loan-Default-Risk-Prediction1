# Loan Default Risk Prediction

## Project Overview

Loan Default Risk Prediction is a Data Science and Machine Learning project that predicts whether a customer is likely to default on a loan.

The project uses customer information such as income, loan amount, credit score, age, loan term and employment status to make a prediction.

## Objective

The main objective of this project is to demonstrate how Machine Learning can be used to identify potential loan default risk.

## Dataset Features

- Age
- Income
- Loan Amount
- Credit Score
- Loan Term
- Employment
- Default

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

## Machine Learning Algorithm

Random Forest Classifier

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Data Visualization
6. Model Training
7. Model Evaluation
8. Prediction

## Model Evaluation

The model was evaluated using:

- Accuracy
- Classification Report
- Confusion Matrix
- Feature Importance

## Conclusion

This project demonstrates the use of Machine Learning for loan default risk prediction. The Random Forest model learns patterns from customer financial information and provides a prediction for potential loan default.
